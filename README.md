# Портфолио

Стек: Vue 3 + TypeScript + Vite, CSS без UI-фреймворка. Локальный запуск: `npm install`, затем `npm run dev`. Проверка production-сборки: `npm run build`.

## Контакты перед публикацией

Сейчас сайт содержит только заготовки, как согласовано. Заполните публичные переменные в локальном `.env.local` или в настройках сборки хостинга:

```text
VITE_OPERATOR_NAME=ФИО или название оператора
VITE_OPERATOR_ADDRESS=Адрес оператора
VITE_CONTACT_EMAIL=hello@example.com
VITE_CONTACT_PHONE=+7 000 000-00-00
VITE_CONTACT_TELEGRAM=https://t.me/username
VITE_CONTACT_WHATSAPP=https://wa.me/70000000000
```

Переменные `VITE_` попадают в публичный JS-файл. Не храните в них пароли, API-ключи и приватные данные. Пустые контакты не отображаются. Перед публикацией заполните в `PrivacyPolicy.vue` срок хранения обращений, поставщика хостинга и срок хранения журналов. Укажите настоящего оператора и проверьте правовые основания обработки в вашей юрисдикции.

## Как работает форма

Форма валидирует имя, email, сообщение и отдельное согласие. После заполнения `VITE_CONTACT_EMAIL` она открывает черновик письма в почтовом приложении посетителя. Пользователь самостоятельно отправляет письмо. Сайт не получает подтверждения доставки. Для отправки без почтового приложения понадобится серверный обработчик с повторной валидацией, антиспамом, ограничением частоты, защитой от CSRF при cookie-сессии и секретами только на сервере.

## Хранение

Выбор в баннере хранится в `localStorage` под ключом `case-portfolio-cookie-choice-v1`. Анимации и SVG-прелоадер запускаются автоматически на всех устройствах. Текущая версия не загружает аналитику или рекламные скрипты. Если они появятся, подключайте их только после явного согласия и обновите политику до релиза.

### Если позже появится API формы

Клиентская валидация не создаёт границу безопасности. Сервер должен проверять схему, размер тела и тип контента, ограничивать частоту запросов, не включать письмо в логи, хранить почтовый ключ вне `VITE_` переменных. Пример серверной проверки:

```ts
const name = String(body.name ?? '').trim()
const email = String(body.email ?? '').trim()
const message = String(body.message ?? '').trim()
if (name.length < 2 || name.length > 100 || email.length > 254 ||
    !/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email) ||
    message.length < 10 || message.length > 3000 || body.consent !== true) {
  return new Response('Invalid request', { status: 400 })
}
```
